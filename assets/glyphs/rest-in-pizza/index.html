Use a glyph

Individual SVG files contain rounded strokes, a 24 × 24 viewBox and an accessible label. Use an empty alt attribute when placing a decorative glyph beside visible text. Inline symbols inherit the surrounding text color.

<svg viewBox="0 0 24 24" width="24" height="24" fill="none"
     stroke="currentColor" stroke-width="1.5" stroke-linecap="round"
     stroke-linejoin="round" aria-hidden="true" focusable="false">
  <use href="sprite.svg#PROPERTY-GLYPH-NAME"/>
</svg>

External sprite references work on a static server. The restaurant sites embed the full property library to support offline file access. The visitor-information glyphs are design resources; their presence in this library does not assert any facility or service.
